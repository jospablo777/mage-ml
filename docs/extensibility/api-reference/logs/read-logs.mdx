title: "Read logs"

---
`GET /api/pipelines/:pipeline_uuid/logs`

<ParamField path="pipeline_uuid" type="string" required>
  Pipeline UUID of the logs.

  Example: `example_pipeline`
</ParamField>

<ParamField query="_limit" type="integer">
  Maximum number of logs to be returned in the API response.

  Example: `20`
</ParamField>

<ParamField query="_offset" type="integer">
  Skip the first N logs, where N equals `_offset`.

  Example: `10`
</ParamField>

<ParamField query="start_timestamp" type="integer">
  Read logs on or after a specified timestamp.

  Example: `1677648116`
</ParamField>

<ParamField query="text" type="string">
  Return only the log lines that contain this text, ignoring case. Up to 200 log files are
  searched, each over all its rotated segments, and files without a matching line are left
  out. The logs page's search box sets it.

  Example: `timeout`
</ParamField>

<ParamField query="log_path" type="string">
  Return a window of the lines of one log file, given by the `path` of a log item. Each item
  carries the newest 5,000 lines of its log (`MAGE_LOG_WINDOW_LINES`), with `first_line`, the
  index of its first line, and `total_lines`, the lines of the log over all its rotated
  segments. With `log_path`, `before_line` (default: the end) and `lines` (default 5,000)
  return the lines before `before_line`. The path must be a log of this pipeline.

  Example: `/home/src/mage_data/default_repo/pipelines/example_pipeline/.logs/54/20230308T045259/load_titanic.log`
</ParamField>

<RequestExample>
```curl cURL
curl --request GET \
  --url 'http://localhost:6789/api/pipelines/example_pipeline/logs?_limit=20&_offset=0&start_timestamp=1677648116&api_key=zkWlN0PkIKSN0C11CfUHUj84OT5XOJ6tDZ6bDRO2' \
  --header 'OAUTH-TOKEN: some_really_long_string'
```
</RequestExample>
