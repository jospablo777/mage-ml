---
title: MongoDB
---

The MongoDB source reads a change stream, which needs a replica set or a sharded cluster.

## Basic Config

```yaml
connector_type: mongodb
connection_str: "mongodb://localhost:27017/?replicaSet=rs0"
database: "test"
# Leave out collection to watch every collection of the database.
collection: "test"
```

The transformer gets a list with one change document. Changes contain MongoDB types such
as ObjectId; sinks that write JSON write ObjectIds as text and BSON timestamps as
`{"t": seconds, "i": increment}`.

## Resuming

After each change the transformer handles, the source saves the change stream's resume
token in the pipeline's streaming checkpoint. A restarted pipeline continues after the
last handled change, so changes made while it was stopped are read, and a change whose
transformer failed is read again. The token is used only for the same database and
collection. If MongoDB no longer has the change in its oplog, the pipeline fails with a
message that names the checkpoint file; delete it to start at the current time.

Without a saved token, the stream starts at the current time, or at:

```yaml
# Seconds since the epoch.
operation_time: 1735689600
# Or a resume token of a change.
start_after: {"_data": "..."}
```

## Other options

`batch_size`, `pipeline` and `full_document` are passed to
[watch](https://pymongo.readthedocs.io/en/stable/api/pymongo/collection.html#pymongo.collection.Collection.watch).
