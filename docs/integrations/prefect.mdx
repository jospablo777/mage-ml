Install MageML and Prefect in the environment that runs your flows, on Python 3.12, in two
commands:

```bash
uv add mage-ml --index mageml=https://jospablo777.github.io/mage-ml/simple/
uv add prefect
```

`uv add` takes every package it names from the index given with `--index`, and Prefect is
not on MageML's index: `uv add mage-ml prefect --index ...` fails with "prefect was not
found in the package registry". With pip:
`python -m pip install -r https://jospablo777.github.io/mage-ml/install/v0.4.0/base.txt prefect`.

Put the MageML project next to your flows (a folder, or a git submodule). The examples
below use a project in `demo_project/` and a pipeline `daily_sales` whose exporter writes
to the path in the `output_path` variable. They were run with Prefect 3.9.5 and MageML
0.4.0, and a failing block fails the Prefect task and the flow with the block's error.

| | One task per pipeline | One process per pipeline | One task per block |
| --- | --- | --- | --- |
| Prefect shows | the pipeline | the pipeline | each block |
| A retry runs | the whole pipeline | the whole pipeline | the failed block |
| Memory | stays in the flow's process | freed when the pipeline ends | stays in the flow's process |
| Branches run at once | as MageML runs them | as MageML runs them | as Prefect tasks |

## One task per pipeline

```python flows/pipeline_task.py
from pathlib import Path

import mage_ai
from prefect import flow, task

PROJECT = str(Path(__file__).resolve().parents[1] / 'demo_project')


@task(retries=2, retry_delay_seconds=30)
def run_pipeline(pipeline_uuid: str, **variables):
    # Runs every block in this process; a failing block raises and fails the task.
    mage_ai.run(pipeline_uuid, PROJECT, **variables)


@flow(log_prints=True)
def daily_sales(output_path: str = 'totals.csv'):
    run_pipeline('daily_sales', output_path=output_path)


if __name__ == '__main__':
    daily_sales()
```

Keyword arguments of `mage_ai.run` are the pipeline's runtime variables
(`kwargs['output_path']` in a block).

## One process per pipeline

```python flows/pipeline_process.py
import json
import subprocess
from pathlib import Path

from prefect import flow, task

PROJECT = str(Path(__file__).resolve().parents[1] / 'demo_project')


@task(retries=2, retry_delay_seconds=30)
def run_pipeline(pipeline_uuid: str, variables: dict):
    # The pipeline in a process of its own: its memory is freed when it ends, and its
    # output goes to the task's log.
    result = subprocess.run(
        ['mage', 'run', PROJECT, pipeline_uuid, '--runtime-vars', json.dumps(variables)],
        capture_output=True, text=True,
    )
    print(result.stdout[-5000:])
    if result.returncode != 0:
        raise RuntimeError(f'mage run {pipeline_uuid} failed:\n{result.stderr[-5000:]}')


@flow(log_prints=True)
def daily_sales(output_path: str = 'totals.csv'):
    run_pipeline('daily_sales', {'output_path': output_path})


if __name__ == '__main__':
    daily_sales()
```

## One task per block

```python flows/block_tasks.py
from pathlib import Path

import mage_ai
from mage_ai.data_preparation.models.pipeline import Pipeline
from prefect import flow, task

PROJECT = str(Path(__file__).resolve().parents[1] / 'demo_project')


@task(task_run_name='{block_uuid}', retries=2, retry_delay_seconds=30)
def run_block(pipeline_uuid: str, block_uuid: str, variables: dict):
    # One block; it reads its upstream blocks' outputs from the project's variables.
    mage_ai.run(pipeline_uuid, PROJECT, block_uuid=block_uuid, **variables)


@flow(log_prints=True)
def pipeline_blocks(pipeline_uuid: str, variables: dict | None = None):
    pipeline = Pipeline.get(pipeline_uuid, repo_path=PROJECT)
    blocks = {
        uuid: block for uuid, block in pipeline.blocks_by_uuid.items()
        if block.type not in ('scratchpad', 'markdown')
    }
    futures = {}
    # Each block starts once its upstream blocks finished; blocks without a path between
    # them run at the same time.
    while len(futures) < len(blocks):
        for uuid, block in blocks.items():
            upstream = [u for u in block.upstream_block_uuids if u in blocks]
            if uuid not in futures and all(u in futures for u in upstream):
                futures[uuid] = run_block.submit(
                    pipeline_uuid, uuid, variables or {},
                    wait_for=[futures[u] for u in upstream],
                )
    for future in futures.values():
        future.result()


if __name__ == '__main__':
    pipeline_blocks('daily_sales', {'output_path': 'totals.csv'})
```

Each block reads its upstream blocks' outputs from the project's variables, as when MageML
runs it, so a retried block gets the same inputs. Blocks in a [Python
worker](/guides/pipelines/python-workers) run in that worker here too.

## Schedule a flow

Prefect schedules flows; a MageML trigger on the same pipeline would run it twice. Serve
the flow with its schedule:

```python
if __name__ == '__main__':
    daily_sales.serve(name='daily-sales', cron='0 6 * * *')
```
