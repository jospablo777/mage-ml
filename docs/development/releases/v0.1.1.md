A security release. Upgrade from 0.1.0 now: any signed-in user, viewers included, could
read any file the MageML server can read, and editors could write, move or delete any file.

## Security

- **The file browser API stays inside the project.** In 0.1.0, `/api/browser_items` took any
  path, so a viewer could read files such as `/etc/passwd` or the server's credentials, and
  an editor could write any file the server can write. Every path, the target of a move or
  rename included, must now be in the project, with symlinks resolved. With authentication
  turned off, anyone who reached the server could do the same.
- **The project check also runs with the project platform**, where it was skipped.
- **Kubernetes credentials stay out of logs and error messages.** With
  `SERVER_VERBOSITY=DEBUG` the Kubernetes client logged every response body, and its errors
  printed the response headers and body; Job and workload bodies hold their environment.
- **Git over SSH**: an existing private key file is made private, which ssh requires, and a
  failed host key scan is reported instead of passing as a success.

## Fixes

- **Pausing or resuming a pipeline on the Pipelines page keeps its settings.** The button
  sent back the list's copy of the pipeline, and block fusion, retries, the environment,
  concurrency and other settings were saved with their defaults in `metadata.yaml`. Check
  the settings of pipelines you paused or resumed there with 0.1.0.
- **A block no longer runs twice** when its process completed while the scheduler checked
  for crashed blocks; an exporter could write its rows twice.
- **Renaming a file in the file browser works.** It failed, and moved the file into the
  server's working folder.

`column-atlas-native` and `mage-integrations` are 0.1.1 and MageML's `singer-python` is
`5.13.0+mage.2`, with no code changes, so the package index accepts the new builds.

## Install or upgrade

```bash
uv add "mage-ml==0.1.1" --index mageml=https://jospablo777.github.io/mage-ml/simple/
```

In a project that already has MageML: `uv lock --upgrade-package mage-ml && uv sync`. With
pip: `python -m pip install -r https://jospablo777.github.io/mage-ml/install/v0.1.1/base.txt`.
All the ways to install are in the
[Quickstart](https://github.com/jospablo777/mage-ml/blob/master/docs-md/getting-started/setup.md).

Wheels are qualified on Linux x86-64 and ARM64 (glibc 2.28 or newer) and macOS Apple
Silicon (macOS 12 or newer), with CPython 3.12.
