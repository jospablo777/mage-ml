The first release of MageML, data and ML pipelines in Python, R, Rust and SQL, built for
ML engineers. MageML is based on Mage 0.9.79, and we are grateful to the Mage team and its
contributors for the work it builds on.

## Highlights

- **Rust blocks** with Polars; consecutive Rust blocks compile into one program.
- **R blocks** with packages locked by rv; consecutive R blocks share one session.
- **Compiled production runs**: triggers and schedules fuse chains of blocks and compile
  them, a performance optimization that makes pipelines faster.
- **Pipeline services**: export one pipeline or a group as a Docker service with an HTTP
  API, schedules, run history, metrics and a terminal console. The **Services** page
  checks a service as you edit, lists the secrets it needs, embeds models from an MLflow
  registry, and builds and pushes the image for amd64 and arm64.
- **After-run triggers**: start a pipeline when another one's run completes or fails, in
  MageML and in exported services; conditional blocks run in services too.
- **ML engineering**: data contracts, run records, MLflow experiments, model release checks,
  monitors, per-pipeline environments, resource limits and a Feast client.
- **Pipeline documentation** in Markdown, Quarto or your own HTML, with images.
- **Pipeline shapes**: a guide, with diagrams, to how a pipeline's shape and languages
  decide its speed, backed by a study of thousands of generated pipelines.
- **ColumnAtlas**: profiles and charts of every block output over the whole dataset.
- Python 3.12, pandas 3, Polars 2, pyarrow 26, NumPy 2, SQLAlchemy 2.
- Self-contained: no usage statistics, no AI features pushed to you, no Mage Pro promotion.

## Install

```bash
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python "mage-ml==0.1.0" \
  --extra-index-url https://jospablo777.github.io/mage-ml/simple/
.venv/bin/mage init my_project && .venv/bin/mage start my_project
```

Wheels are qualified on Linux x86-64 and ARM64 (glibc 2.28 or newer) and macOS Apple
Silicon (macOS 12 or newer), with CPython 3.12. macOS on Intel is not supported: a
required dependency, cryptography, no longer ships Intel macOS wheels. Rust blocks need
Rust on the machine that builds them, and R blocks need R and rv.
